# NeuroAudio

Base inicial del proyecto para un reproductor de audio para bienestar mental.

## Estructura

- src/features: dominios del producto (catalog, player, etc.).
- src/components: componentes de UI reutilizables.
- src/lib: utilidades y el futuro motor de audio desacoplado.
- src/types: tipos TypeScript compartidos.
- src/hooks: hooks reutilizables.
- src/styles: estilos globales y temas base.

## Desarrollo

1. Instala dependencias con npm install.
2. Inicia el entorno con npm run dev.
